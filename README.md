# حفلة البط (Duck Party)

لعبة بارتي بورد لنادي العلوم البيولوجية. شاشة عرض (بروجكتر) + كل لاعب يلعب من تلفونه.

## التشغيل

```bash
npm install
npm run dev
```

- **شاشة العرض:** افتح `http://localhost:5173/?screen` على اللابتوب المربوط بالبروجكتر.
- **اللاعبين:** يصورون الـ QR اللي على الشاشة، أو يفتحون الرابط اللي تحته. لازم التلفونات واللابتوب **على نفس الشبكة** (نفس الواي فاي أو الهوت سبوت).
- أول لاعب يدخل يصير **المنظم**: يحدد عدد الجولات، ويضيف بطات كمبيوتر، ويبدأ اللعبة، وعنده زر "تخطي" إذا أحد علّق.

### تشغيل نسخة نهائية (بدون وضع التطوير)

```bash
npm start
```

يبني اللعبة ويشغلها كلها على منفذ واحد (`PORT`، والافتراضي 3001).

## الاختبار (بدون تلفونات)

`npm run dev` لازم يكون شغال.

```bash
npx tsx tools/sim.ts 2
```

يلعب لعبة كاملة من جولتين بلاعبين وهميين عن طريق السيرفر مباشرة، ويطبع كل مرحلة.

```bash
npx tsx tools/shots.ts shots 2
```

يفتح الشاشة الكبيرة وتلفونين بمتصفح مخفي (Chrome المثبت على الجهاز)، ويلعب لعبة كاملة، ويحفظ صورة لكل مرحلة بمجلد `shots`.

```bash
MODE=minigames npx tsx tools/shots.ts shots
```

يدخل كل ميني قيم مباشرة ويصورها: المقدمة، والعد، واللعب، والنتايج.

## الموجود حالياً

- غرف برمز وQR، ودخول من التلفون بدون تسجيل، وإعادة اتصال تلقائية
- ١٦ قطعة يختار منها كل لاعب باللوبي، وحتى ٨ لاعبين
- بورد الجزيرة: ١٠٧ خانات، و٣ تفرعات، وطريق المنارة
- خانات: فتات، ومصيبة، وحدث، وصندوق، ومبارزة، ومنارة، ونجمة تتنقل
- ٥ أحداث، و٣ أغراض (نرد مضاعف، وسرقة، ودرع)
- ٤ ميني قيمز تنعرض حية على الشاشة الكبيرة: ١٠ ثواني، ولا تقوم!، وسباق التجديف، واوقف ولا كمّل
- مبارزات ١ ضد ١، وآخر جولة دبل، وجوايز مخفية بالنهاية، ومنصة الفايزين
- لاعبين كمبيوتر يكملون العدد، ولعب تلقائي إذا أحد طوّل أو فصل

## الناقص (المراحل الجاية)

- وضع البوث (جولات قصيرة ولوحة أبطال اليوم)، والوضع العادي من البيوت
- بورد الحية والدرج
- باقي الميني قيمز، والعوائق المتحركة، والاختصارات (السحّاب والكهف)
- أصوات حقيقية (الحالية مولدة بالكود)

## المنظم: يلعب أو ينظم بس

أول واحد يدخل من تلفونه هو المنظم. باللوبي يقدر يضغط "ما راح ألعب، بنظم بس"، وجذي:
- يطلع من قائمة اللاعبين، وما ياخذ دور ولا يدخل الميني قيمز.
- تلفونه يصير لوحة تحكم فيها الترتيب وحالة اللعبة وزر التخطي، وزر "لعبة جديدة" بالنهاية.
- إذا طلع وارجع بنفس التلفون يرجع منظم. وإذا انقطع، أول لاعب متصل ياخذ صلاحيات المنظم احتياط.
- يقدر يرجع يلعب بزر "أبي ألعب بعد" قبل ما تبدأ اللعبة.

## الخانات الخاصة

ترتيبها على الخريطة بالسكربت `python -I tools/board_specials.py`، وتشغله بعد `tools/build_board.py`. السكربت يختار الخانة الأقرب لكل مكان بالرسمة.

| الخانة | وين | شو تسوي |
|---|---|---|
| الدكان ($) | دكان الشجرة، سوق المزرعة | توقف عنده إذا مريت عليه أو وقفت فيه، وتشتري غرض واحد بالفتات |
| عجلة الحظ | ٣ خانات ملونة | توقف العجلة من تلفونك. فيها: +١٢، أو -١٠، أو نجمة، أو تخسر نجمة، أو تتبدل مع الأول، أو غرض، أو الكل يعطيك، أو تعطي الكل. والدرع يحميك من السلبي |
| الكهف السري | تحت الكهف | نفق يطلعك عند الرصيف |
| قارب البركة | الرصيف | القارب يعبر فيك البركة |
| الحبل الطاير | جنب البرج | تنزل بالحبل لين العمود اللي تحت |
| الشلال | الجسر | الجسر زلق والشلال يسحبك ٣ خانات لورا (الدرع يحميك) |
| مزرعة البقرة | المزرعة | حصاد: ٤ + رقم الجولة فتات |
| نافورة الأمنيات | تحت البركة | ترمي ٥ فتات: يا غرض، يا ١٤ فتات، يا ما يصير شي |

**الدكان:** نرد مضاعف ٥، ونرد ثلاثي ١٠، ودرع ٤، وسرقة ٧، وبوابة النجمة ١٥ (تنقلك لين جنب النجمة). الأسعار في `SHOP_STOCK` بملف `src/shared/data.ts`، ونسب العجلة في `WHEEL`.

لما يوقف أحد على مكان من الخريطة، الشاشة تطلع "صورة" دايرية للمكان مقصوصة من رسمة الجزيرة نفسها.

## بورد الحية والدرج

المنظم يختار البورد من تلفونه باللوبي: "جزيرة البط" أو "الحية والدرج".

**القوانين (مسوية عشان تناسب الحفلات):**
- كل دور ترمي **نردين**، فالسباق يمشي بسرعة. وإذا طلع لك دبل ترمي مرة ثانية، بس مرة وحدة بالدور.
- سلالم الـ DNA تطلعك لفوق، والحيات تنزلك لين ذيلها.
- إذا عديت ١٠٠ ترتد لورا بالخطوات اللي زادت.
- كل ٣ جولات فيه ميني قيم، والفايزين يتقدمون خطوات زيادة: الأول ٥، والثاني ٣، والثالث ٢، والرابع ١.
- أول واحد يوصل خانة ١٠٠ (التاج) يفوز. وإذا خلصت الجولات (٢٠ جولة افتراضياً)، يفوز اللي وصل أبعد خانة.

**على الشاشة:**
- أرقام الخانات مكتوبة فوق الرسمة: الأخضر بداية درج، والأحمر راس حية.
- القطعة تطلع الدرج نطة على كل درجة، وتنزلق على جسم الحية المرسوم لين ذيلها.
- البطاقات والجولة على اليسار، والإعلانات والنرد على اليمين، عشان ما يتغطى أي مربع، والكاميرا ما تقرّب على هالبورد.

**الرسمة والبيانات:**
- الرسمة الأصلية محفوظة في `tools/src-art/snakes-original.webp`.
- `python -I tools/build_snakes.py` يحسب الشبكة من خطوطها، ويرقّم الخانات بشكل متعرج (١ تحت يسار، و١٠٠ فوق يسار).
- نفس السكربت يحدد كل حية وكل درج من وين يبدأ ولوين يوصل، ويحفظ مسار جسم كل حية في `src/shared/board-snakes.json`.
- ويطلّع النسخة المكبّرة `public/assets/snakes-hd.jpg`. إذا زدت `--debug out.png` يرسم المسارات فوق الصورة عشان تتأكد منها.
- إذا غيّرت الرسمة، عدّل الأرقام في `X` و`Y` و`LADDERS` و`SNAKES` داخل السكربت.

**قوانين السباق:**
- القوانين في `src/shared/rules.ts`: خطوات المكافأة (`RACE_STEPS`)، وكل كم جولة فيه ميني قيم (`RACE_MG_EVERY`)، وعدد الجولات الافتراضي.

**الاختبار:**
```bash
BOARD=snakes npx tsx tools/sim.ts 20
```
لعبة سباق كاملة بالمحاكاة.

```bash
npx tsx tools/race-shots.ts shots-race
```
يفرض قيمة النرد عشان القطعة توقف على درج وعلى حية، ويصوّر الطلعة والنزلة. يحتاج `dev:dice`، وهو أداة اختبار بس.

`BOARD=snakes` يشتغل بعد مع `tools/shots.ts`.


## لعبة الكروت "كواك!"

المنظم يختارها من تلفونه باللوبي، مع البوردات. كل لاعب يشوف كروته على تلفونه بس، والشاشة الكبيرة تعرض الطاولة: الكوم، آخر كرت انلعب، واللاعبين حوالين الطاولة وكم كرت عند كل واحد.

**القوانين:**
- كل لاعب ياخذ ٧ كروت. تلعب كرت بنفس اللون أو نفس الرقم أو نفس النوع، أو كرت ألوان.
- إذا ما عندك كرت ينلعب، تسحب كرت واحد. إذا كان ينلعب، تقدر تلعبه على طول أو تخليه.
- **اوقف:** اللي بعدك يطير دوره.
- **عكس:** يتعكس اتجاه اللعب. إذا كنتوا لاعبين بس، يصير مثل اوقف.
- **+٢:** اللي بعدك يسحب ٢.
- **قرار الدكتورة:** تختار اللون.
- **+٤:** تختار اللون، واللي بعدك يسحب ٤.
- **تبديل العينات:** تبدّل كروتك كلها مع لاعب تختاره، وتختار اللون.
- تقدر تكدّس: +٢ فوق +٢، و+٤ فوق +٢ أو +٤. اللي ما عنده يكدّس ياخذ المجموع كله.
- **كواك!** لما يبقى عندك كرت واحد لازم تضغط "كواك!" خلال ٣ ثواني. إذا أحد ضغط "مسكتك!" قبلك، تسحب كرتين. وتقدر تصيحها من قبل، وانت ماسك كرتين بدورك.
- أول واحد يخلّص كروته يفوز. الباقين يترتبون حسب عدد الكروت اللي باقية عندهم.
- الدور له ٢٥ ثانية. إذا خلص الوقت، يسحب اللاعب كرت ويكمل الدور. والمنظم يقدر يضغط "تخطي" عشان الكمبيوتر يلعب الدور عنه.

**الكوتشينة (١١٠ كروت):**
- كل لون فيه: ٠ مرة وحدة، ومن ١ لين ٩ مرتين، و٢ من كل كرت (اوقف، عكس، +٢).
- وفوقها: ٤ قرار الدكتورة، و٤ +٤، و٢ تبديل العينات.

**الشخصيات (بطات النادي):**
- كروت الأرقام: كل لون عليه بطة. الأصفر بسام، والأحمر كيراز، والأخضر أحمد، والأزرق عبدالله.
- الكروت الخاصة مثل الشايب والجوكر بالبلوت: كل كرت له بطة ووضعية خاصة فيه، مع إطار ذهبي وشريط فيه اسمه.
  - اوقف: "استراحة قهوة" (بسام)
  - عكس: "تفاعل عكسي" (الجمل)
  - +٢: "تكاثر" (رؤى)
  - "قرار الدكتورة" و"واجب إضافي" (+٤): د. زهراء
  - تبديل العينات: عبدالله
- أوراق الشخصيات الأصلية محفوظة في `tools/src-art/club/`.

**صور الكروت:**
- الصور الحالية مؤقتة: مقصوصة من أوراق الشخصيات بـ `python -I tools/cut_club_cards.py`.
- الصور النهائية تتسوى بـ ChatGPT بالبرومبتات اللي في `docs/card-art-prompts.md`.
- لما توصل الصور النهائية: حطها في `tools/src-art/club/final/` بنفس الأسماء (`y.png`، `skip.png`...)، وشغّل:
```bash
python -I tools/cut_club_cards.py --final
```

**الكود:**
- القوانين والكوتشينة: `src/shared/cards.ts`
- السيرفر والبوتات: `src/server/cards.ts`
- رسمة الكروت: `src/client/cards-ui.ts` و`src/client/cards.css`
- الطاولة: `src/client/display/table.ts`
- التلفون: `src/client/controller/cardpad.ts`

**الاختبار:**
```bash
npx tsx tools/cards-sim.ts 3
```
لعبة كاملة بالمحاكاة: لاعبين اثنين وبوتات. يتأكد إن كل كرت انلعب كان مسموح، وإن الشاشة الكبيرة ما توصلها كروت أحد.

```bash
npx tsx tools/cards-drive.ts <CODE> 3 2
```
يدخل غرفة مفتوحة على الشاشة كمنظم، ويختار الكروت، ويضيف بوتات، ويبدأ أول ما يدخل لاعبين اثنين. تقدر تدخل انت من التلفون وتلعب.

صفحة `/?cards=200` تعرض كل أنواع الكروت جنب بعض عشان تشيّك على الرسمة. و`npx tsx tools/cards-thumb.ts` يطلّع الصورة المصغرة حقت اختيار اللعبة.

## العب على جهاز واحد (بدون بروجكتر وبدون سيرفر)

من الصفحة الرئيسية اضغط "العب على هالجهاز". كل شي يصير على شاشة وحدة، سواء كمبيوتر أو تلفون.

**الإعدادات:**
- تختار اللعبة: جزيرة البط، أو الحية والدرج، أو كواك!
- تختار كم واحد بيلعب على الجهاز: بروحك أو اثنين.
- تختار كم لاعب كمبيوتر يكمّل معاكم، وعدد الجولات.

**الشاشة:**
- البورد ياخذ الشاشة، وكل لاعب له لوحة على الجنب. اللوحة هي نفس شاشة التلفون، وفيها نفس الأزرار.
- على التلفون العمودي: البورد فوق واللوحات تحت. وإذا قلبت التلفون بالعرض، يصير البورد أكبر.
- إذا كنتوا اثنين، بالميني قيمز الأول يضغط <kbd>A</kbd> والثاني <kbd>L</kbd>. ولو فيه خيار ثاني: <kbd>S</kbd> للأول و<kbd>K</kbd> للثاني.
- إذا كنتوا اثنين بلعبة الكروت، كروت كل واحد تنقلب على وجهها إلا بدوره، عشان ما يشوف الثاني كروته.

**وين يشتغل؟** سيرفر اللعبة نفسه يشتغل داخل الصفحة (`src/client/local-server.ts`)، فما يحتاج إنترنت ولا سيرفر. عشان كذا ينفع ينرفع على GitHub Pages:

https://q8hitman.github.io/bsc-boardgame/

**التحديث:** إذا عدلت شي وتبي تحدّث النسخة اللي على GitHub Pages:
```bash
npx tsx tools/deploy-pages.ts
```
هذا الأمر يبني اللعبة ويرفعها على فرع `gh-pages`.

**البروجكتر والتلفونات:** هالطريقة للحين تحتاج سيرفر اللعبة يشتغل على جهاز (`npm run dev` أو `npm start`)، لأن GitHub Pages ما يشغّل سيرفرات.
